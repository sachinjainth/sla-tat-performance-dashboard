
# SLA & TAT Performance Dashboard

## Project Overview

This project demonstrates an operational reporting solution built using Microsoft Excel, Power Query, and Power BI to monitor ticket turnaround time (TAT), SLA compliance, SLA breaches, and team performance.

## Key Results

- Total Tickets: 35
- Average TAT: 27.5 hours
- SLA Compliance: 82.35%
- SLA Breaches: 6
- Open Tickets: 1

## Key Insight

Technical SLA compliance is 68.75%, compared with 94.44% for Support, despite similar average turnaround times.

## Tools Used

- Microsoft Excel
- Power Query
- Power BI
