
# Power BI Sales Performance Dashboard

## Project Overview

This project demonstrates the use of Microsoft Power BI to analyze sales performance, monitor key performance indicators (KPIs), and identify areas that require business attention.

## Objectives

- Monitor sales performance against targets.
- Compare performance across different regions.
- Track error rates and identify areas for improvement.
- Present business insights through dashboard visualizations.

## Tools Used

- Microsoft Power BI
- Data visualization and KPI reporting
- Business performance analysis

## Key Analytical Areas

- Regional performance comparison
- Target achievement analysis
- Error rate monitoring
- Identification of priority areas for management attention
